shortstool

A private, single-user desktop tool for making and publishing Shorts to my own channels.

What it is

shortstool is a personal command-line tool that runs only on my own Windows PC. It helps me write, voice, edit and publish short vertical videos (Shorts) for the channels I own and operate in several languages (Korean, English, Japanese and Spanish).

It is not a public service. There is no sign-up, no other users and no hosted server. This page exists to describe the tool and its data handling for the API review.

How it uses the YouTube API

PurposeScope / method
Upload a finished video to my own channel with its title, description, tags, thumbnail and scheduled publish timeyoutube.upload — videos.insert, videos.update (status), thumbnails.set
Check processing status and view counts of my own uploads after 24 hours and 7 days youtube.readonly — videos.list, channels.list (mine)
Research which public Shorts perform well in my genres, to plan my own original videos API key (public data only) — search.list, videos.list, channels.list

Workflow

  1. I prepare a video and its script on my PC.
  2. I watch the final video to the end and approve it myself. Nothing is uploaded without this human review.
  3. The tool uploads the video as private to my own channel.
  4. I check the copyright result in YouTube Studio, then the video is scheduled to publish.
  5. The tool reads the view count of my video after 24 hours and 7 days for my weekly report.

Expected volume: about 2 uploads per channel per day (about 6–8 per day in total) and a few status reads.

Data

All data stays on my own PC. Sign-in tokens are kept in the Windows Credential Manager. Nothing is sold, shared or sent to third parties. See the privacy policy.
