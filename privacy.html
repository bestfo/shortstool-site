Privacy Policy

Effective date: November 10, 2026

Who uses this tool

shortstool is a private desktop tool used by a single person (its developer) on their own PC to manage YouTube channels they own. It is not offered to the public and has no other users.

YouTube API Services

shortstool uses YouTube API Services. By using it, you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What data is accessed

  • Google sign-in for my own channels (scopes youtube.upload and youtube.readonly): used to upload my videos and to read the status and view, like and comment counts of my own uploads.
  • Public YouTube data (API key): titles, channel names, view counts and publish dates of public Shorts, used only to research trends for my own original videos.

No personal information of other people (such as viewers' names, emails or comments) is collected.

How data is stored

  • Sign-in (OAuth) tokens are stored only in the operating system's credential store (Windows Credential Manager) on my PC.
  • Upload records and view counts are stored in a local database file on my PC.
  • Public data used for trend research is stored locally and used only for my own planning.
  • No data is stored on any server, and there is no analytics or tracking.

Sharing

Data is not sold, shared, or transferred to any third party.

Google API Services User Data Policy

shortstool's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Data deletion and revoking access

  • Access can be revoked at any time on the Google security settings page.
  • Deleting the tool's local data folder and its credential store entries removes all stored data.

Changes and contact

If this policy changes, the new version will be posted on this page with a new effective date. Questions: open an issue on this site's repository.
